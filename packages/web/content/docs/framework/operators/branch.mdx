title: branch
description: Conditional routing -- pick one step to execute or skip entirely.
---

## Quick Example

```ts
import { branch, step } from '@noetic-tools/core';

const triageAgent = branch({
  id: 'triage',
  route: (input: string, ctx) => {
    if (input.includes('urgent')) {
      return step.llm({
        id: 'urgent-handler',
        model: 'openai/gpt-4o',
        instructions: 'Handle this urgent request immediately.',
      });
    }
    if (input.includes('ignore')) {
      return null; // skip -- no step executed
    }
    return step.llm({
      id: 'default-handler',
      model: 'openai/gpt-4o-mini',
      instructions: 'Handle this routine request.',
    });
  },
});
```

## What It Does

`branch` is a runtime router. Its `route` function receives the step input, the context, and a `run` function, and returns either:

- A `Step` to execute, or
- `null` to skip (the input passes through as-is).

This is the idiomatic way to add conditional logic to an Noetic pipeline. Instead of if/else blocks around step calls, you express the decision as data.

## API Reference

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Unique step identifier |
| `route` | `(input: I, ctx: Context<TContext>, run: ExecuteStepFn) => Step<TContext, I, O> \| null \| Promise<Step<TContext, I, O> \| null>` | Yes | Function that picks the step to run (sync or async) |

## Running a Step to Choose

The third argument, `run`, executes a step through the interpreter and returns its output. Use it when the route must run a step to choose, such as a decision. A step run this way gets the same treatment as any other step: its own span, its usage and cost on the context, and its layer hooks.

```ts
import { branch, step } from '@noetic-tools/core';

const check = step.decide({
  id: 'check',
  model: 'typesafe/jev-1.14',
  questions: {
    isUrgent: {
      type: 'boolean',
      instructions: 'Is the customer reporting downtime?',
    },
  },
});

const urgent = step.llm({
  id: 'urgent',
  model: 'openai/gpt-4o',
  instructions: 'Handle this urgent request immediately.',
});

const router = branch({
  id: 'urgent-router',
  route: async (input: string, ctx, run) => {
    const answers = await run(check, input, ctx);
    if (answers.isUrgent.type === 'refusal' || !answers.isUrgent.value) {
      return null;
    }
    return urgent;
  },
});
```

[`step.routeSwitch`](/docs/framework/operators/route-switch) is built this way: a branch whose route runs a decide step and picks a case from the answers.

## How Null Routes Work

When `route` returns `null`, the branch is skipped entirely. The input value is passed through as the output. This is useful for optional processing steps.

```ts
import { branch, step } from '@noetic-tools/core';

const maybeTranslate = branch({
  id: 'maybe-translate',
  route: (input: { text: string; lang: string }) => {
    if (input.lang === 'en') {
      return null; // already English, skip
    }
    return step.llm({
      id: 'translate',
      model: 'openai/gpt-4o',
      instructions: `Translate the following text to English.`,
    });
  },
});
```

## Dynamic Step Creation

The `route` function creates steps at runtime, so you can parameterize them based on input.

```ts
import { branch, step } from '@noetic-tools/core';

const modelPicker = branch({
  id: 'model-picker',
  route: (input: { task: string; budget: 'low' | 'high' }) => {
    const model = input.budget === 'high' ? 'openai/gpt-4o' : 'openai/gpt-4o-mini';
    return step.llm({
      id: `${input.task}-llm`,
      model,
      instructions: `Perform the following task: ${input.task}`,
    });
  },
});
```

## Nesting Branches

Branches can return other branches, forks, or any other step type.

```ts
import { branch, fork, step } from '@noetic-tools/core';

const nested = branch({
  id: 'outer',
  route: (input: string) => {
    if (input === 'compare') {
      return fork({
        id: 'compare-models',
        mode: 'all',
        paths: () => [
          step.llm({
            id: 'model-a',
            model: 'openai/gpt-4o',
          }),
          step.llm({
            id: 'model-b',
            model: 'openai/gpt-4o-mini',
          }),
        ],
        merge: (results) => results.join('\n---\n'),
      });
    }
    return step.llm({
      id: 'single',
      model: 'openai/gpt-4o',
    });
  },
});
```

## Semantic Routing

The `route` function can be async, enabling AI-powered and embedding-based routing. Noetic provides condition helpers like `semanticSwitch`, `semanticRoute`, `embeddingMatch`, and `aiCondition` that return async route functions:

```ts validate=none
import { branch, semanticSwitch, step } from '@noetic-tools/core';

const router = branch({
  id: 'semantic-router',
  route: semanticSwitch({
    embed,
    cases: {
      'greeting or salutation': step.llm({ id: 'greet', model: 'openai/gpt-4o-mini' }),
      'technical question': step.llm({ id: 'tech', model: 'openai/gpt-4o' }),
    },
    threshold: 0.7,
  }),
});
```

See [Semantic Conditions](/docs/framework/operators/conditions) for the full API, including condition combinators, caching, and custom conditions.
